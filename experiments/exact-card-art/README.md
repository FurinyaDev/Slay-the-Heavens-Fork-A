# M8 三张原生精修卡的无损编码

TASK-25／TASK-10.1.2／TASK-105 的 A1/A2 离线实验。仅使用整备武装（`armaments`）、星陨剑（`cleave`）和重剑斩（`heavy_blade`）既有 Owner 认可的三张原生精修，不修改其源图、画风、坐标、RGBA、图层顺序或原生图库编号。生产构建、美术策略和共享渲染器维持现行行为。

现有装配为每个图元重复写入具名字段、居中锚点和常规缩放。实验在离线构建中将这些固定值和可由序号导出的宿主路径移出 6,534 个图元的序列化记录。坐标、旋转和色值继续使用原始数字。模块加载时恢复现有渲染器的完整数据格式，每个图元仍拥有独立的变换表。压缩包只含这三个稳定 ID。构建在字段、维度、锚点或宿主路径不匹配时停止。

| 三图 Lua（含实验解码器） | 字节数 |
| --- | ---: |
| 既有序列化入口 | 2,217,195 |
| 实验序列化 | 885,127 |
| 减少 | 1,332,068（60.1%） |

采用相同的 Lua 仿真宿主和共享 CardDisplay 验证逐字段数据与实写图元一致。三图依次切换时保留默认图标回退，清理后图元全数销毁，池计数为 0。单次 Fengari 采样的 `loadfile`／模块执行分别为 0.458／0.149 秒与 0.233／0.455 秒。编码减少离线 Lua 字节，模块执行需要额外解码并构造表。该采样使用本地仿真宿主，官方加载、峰值内存与设备成本保持 **UNVERIFIED**。

## 重放

在干净工作树下执行。每次选全新的输出名称。

```sh
npm ci
npm run build:data
npm run build:ui
node --test experiments/exact-card-art/build.test.mjs
node experiments/exact-card-art/build.mjs build/exact-card-art-a12
```

输出包含 `baseline/abyss_ready_card_assets.lua`、`packed/abyss_ready_card_assets.lua` 和绑定源码、解码器、原始绘图及两个生成模块 SHA-256 的 `comparison.json`。测试同时验证多余坐标值、锚点变化及错误路径被拒绝，并以现有共享宿主比较两份数据的创建、切换和释放。

当前缺经授权的可导入底图副本、千星 SDK／编码器和可获批的三图隔离导入路线。取得这些输入后，在相同底图和宿主上比较两个冻结候选的官方存档、PC 与实体手机负载。官方容量、完整 A3 量产和其他职业卡图仍按现有准入验收。
