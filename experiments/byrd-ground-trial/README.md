# v2.2.0 巡风隼落地试验

适用 TASK-115.7.3。当前是隔离运行试验，正式分支沿用已验的现有战斗构建。绘图稿复用项目的巡风隼头、喙、眼和胸腹。26 个原生图元在同一角色的 41 槽池内绘制新翅膀、尾部、前后脚。击落后和地面头槌阶段启用，直到实际飞行层数恢复。关闭正式怪物图时保留已有后备美术、站位和待机动作。

收翼状态以 106 像素图的可见冠部与脚底推导目标区。命中和意图共用该边界，沿用 44 像素最小区域。生命条保持原尺度与落点。两脚阴影复用原有控件。强制显隐、罩图和界面关闭仍由原有控件生命周期管理。

从仓库根运行 `node experiments/byrd-ground-trial/test.mjs`。入口先在临时目录生成正式精绘与真实原生模板配置，再执行实际玩法、动作序列和控件断言。验证包括 Flight 1→0、眩晕、头槌与真正恢复 Flight 3，60 次静止无新增图元或落点写入，禁用原生怪物图时的旧图与坐标，以及新战斗复用时释放旧所有者。试验的实际截图和点击结果与各自精确来源单独保存。

候选 `fadb23a6` 的原落地试验留下过高的飞行命中框与意图间距，作为相同遭遇下的实渲反例。后续正式接入以独立视觉评审、完整性能、真实平台和设备结果为准。
