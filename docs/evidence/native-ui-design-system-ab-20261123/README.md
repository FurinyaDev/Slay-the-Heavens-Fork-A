## 商店动画的工程成本

沿用首轮 0.30 s、30／60／120 Hz 的同轨迹证据。本轮分别验证真实 SDK 的重进、20 次启动后中断、退出、停用、会话销毁、仅销毁目标、旧回调及两个 Tween 中同一个子回调的重复注入。三版的正常完成点一致。回放在 VM 存活时注入旧回调，销毁后检查运行时控件、脚本、回调和动画注册表。上一轮双 Tween 的共享递减计数会被重复子回调提前耗尽，本轮按子句柄去重。

| 版 | 正常阶段 Lua 位置提交 | SDK 插值 | 调用方动画句柄 | 完成与清理 |
| --- | ---: | ---: | ---: | --- |
| Lua | 38 | 0 | 0 | 一个活动记录、一个时钟、到位结束。 |
| 双 Tween | 2 | 36 | 2 | 两个子完成回调去重，聚合完成，取消逐个 Kill。 |
| Sequence | 2 | 36 | 1 | 两个插值子轨，一次完成回调，一次 Kill。 |

三版正常阶段各有 38 次位置通知。按策略专属实现行数统计，Lua 为 7 行，双 Tween 为 14 行，Sequence 为 7 行。两种原生方案各计入 4 行共用 Tween 构造，三个样本共用的所有权检查、取消和测试输入不计入此列。原生版仍在活动期检查目标存活。Sequence 优于两个独立 Tween 的句柄维护；单计时器 Lua 的代码和取消路径仍较短。正式商店还需要货架就绪、离店事务、视口变更、切房间和输入保护，迁移需验证这些路径和官方设备。 [上一轮商店轨迹和 NO-GO](../native-ui-animation-ab-20261123/README.md)

## 集成顺序

1. **GO** 先做语义主题入口与 69 控件按钮的小 PR，先选已核对状态引用的预设路径。保留旧 Lua 所有权与点击几何。
2. **HOLD** 单独接入 Skip 隐藏层精简，先走正式资产配置的完整领取／跳过／地图返回回归。面板样式各自独立审核。
3. **HOLD** 用一个可回退的小 PR 试商店 Sequence。保持当前配对参数，验货架就绪、点击保护、重入、离店和真机。
4. **HOLD** 有真实素材与设备后再做 Stretch 或重点 Hover。保证两层素材、实际切片、色彩和帧时证据完整。全局拖尾、当前 `106030` 双层配对以及此前三项 Tween 否决方案无需继续投入。
