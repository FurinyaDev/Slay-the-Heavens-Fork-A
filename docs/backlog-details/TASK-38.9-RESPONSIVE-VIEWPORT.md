## 共享实现

- 最外层原生锚定底图保持常驻。Lua 启动和画布变化时计算同一个视口。中心舞台可占满逻辑画布，旧 1280×720 内容坐标使用一个等比系数。墙面、地面、顶栏材料和遮罩按可绘制范围扩展。场景图用同一轴比例放大、居中裁切。开局恩赐只延长每行最外侧砖块，并延展场景底和地面。雕像、选项和气泡继续使用现有坐标和尺寸。
- 视觉与输入使用各自的矩形。横屏手机报告 16:9 或更宽时，沿用 DIAG‑12 的 400 UI 单位视觉余量。真实比例可能小于该绘制范围，因此等比铺展的场景有裁切，选角原生合成图也包括在内。控件拦截、拖放、地图逆变换仍使用逻辑输入画布。设置和牌组入口按逻辑边界内移。其余 HUD 热区、刘海、圆角和手势区域仍需设备核验。
- 公用全屏遮罩使用视觉范围，退出、牌组、遗物、选牌和药水外点接收器使用输入范围。局部牌组遮罩继续使用其局部矩形。战斗、商店与开场的动态遮罩在 resize 后保留已有输入世代和动画归属。
- 复用原有图元与图片资源。新增工作跟随已有启动与 resize 调用，屏幕尺寸稳定时不遍历布局。
