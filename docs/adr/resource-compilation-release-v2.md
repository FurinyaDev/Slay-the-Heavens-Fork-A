# Release v2.0.0 资源编译决策

## Requirements

以 `release/v2.0.0` 的 `380ffdd8de10ffb8472a48725c438c3f77c0d3d4` 为对照。用同底图、同精绘档、同发行说明和音频入口比较最终 GIL。保留战斗、选角、地图、商店、奖励、事件和旧回调的原有行为。官方关卡 20 MB、服务器 3 MB、内部预警 16 MB 取同候选官方读数。

## Entities

原始素材和主题仍是视觉权威。现有布局生成器输出逻辑控件和正式计划。布局编译可对完全等价的视觉定义择优存储，运行时控件及其输入、位置、着色和生命周期继续由原页面持有。模板 ID 属于候选。正式装配由生产清单控制，容量收据绑定完整有声产物、基底、源码、构建 ID 和 payload 摘要。

## Approach

| 决策 | 依据 |
| --- | --- |
| 保留 Release 的内联卡面 | #703 的原生引用在历史非官方配置通过写入读回。当前精绘配置的真实模拟宿主中，原生引用可读出模板 ID，`GetChild` 无法取得后代。内联与显式实例化的正控均能取得后代。卡组、锻造和牌堆继续使用原有查找与回收规则。 |
| 在地图返回复用一份圆角材质 | 该入口已经由 GameUI 处理四态和触控取消。只接受解析后除颜色外完全一致的状态树，保留原 caption、hit、状态投影路径和静止时的写入抑制。几何或子层契约变化时沿用显式状态树。牌堆返回已有一份材质。原生 `presetButton` 和奖励行的自动状态转换缺少独立的颜色投影确认，保留其模板。 |
| 仅在正式画像投影排除 `selection133` | 正式消费者直接选已批准的 `lowpolyLumine`，独立保留缩略图和已批准的战斗画像。历史配置的资源保持可生成。 |
| 按模块选择 Lua 存储表示 | 保留 v1 的历史读回配方。正式 v2 可使用精确十进制短写、合法 Lua 字段标识符和少量局部数字常量。重复表结构沿用 v1 的构造器，保留独立表。生成器选实际更小的文本，启动标记和模块 ABI 沿原入口。 |

## Structure

`data/` 与既有布局、画像生成器供给逻辑表示。`native-rounded-button.mjs` 与 `native-script-storage.mjs` 在现有构建边界编译存储表示。生产脚本白名单、候选模板注册、音频装配、require 路径和源快照审计继续使用同一条构建链。

## Operations

对精确 Release 源作独立无声与有声清单确认。最终容量以有声产物为准。用 `compare-native-resource-builds.mjs` 对照两份 `audio/candidate.json`。原生 UI、Lua、图及逻辑计量单独列出。设备、官方导入、动态负载和音频试听按同候选的发布规约验收。

## Norms

保留 #861 已达到的 Lua 收益，历史回放使用固定生产者。启用新的共享候选需重放展开、原生查找、状态隔离、回收和销毁的正反例。#869 的按钮产品设计由原 PR 管理，#872 与 #857 是已经落入 Release 的内容的 Develop 回流。按 Owner 指定的 Release 管理员 PR 通道集成经独审的候选。

## Safeguards

真机结果、官方容量和正式发布维持发布候选门禁。多因素比较以实际组合为准。未经证明可独立实例化的卡面与没有无引用证明的隐藏底板不进入本次裁剪，且保留失败实验。
